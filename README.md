# Traffic Simulation Engine
A Python-based 2D traffic simulation built with Pygame.

## Current Features
- Simulation window
- Road and car visualisation
- Basic car movement
- Frame-rate control

## Planned Features
- Vehicle and traffic-light classes
- Adaptive traffic-light control
- Traffic-aware routing
- Performance comparisons

## Requirements
- Python 3.13+
- Pygame 2.6.1

## Run
Install Pygame:
`python -m pip install pygame==2.6.1`

Run the simulation:
`python main.py`
## Status
Early development. Adaptive control and performance comparisons are not implemented yet
